## 📖 Overview

**Zenoa AI** is a cross-platform mobile application that turns text descriptions and reference images into digital art, anime illustrations, avatars, and high-resolution wallpapers. Designed with an offline-first mindset, rich customization, and a built-in community feed, Zenoa AI v3 brings together fast image generation, multi-language support, and customizable theming in a clean mobile experience.

Learn more on the [Zenoa AI Showcase](https://sumitrathore.web.app/zenoa-ai) or visit [zenoa-ai.web.app](https://zenoa-ai.web.app).

## ✨ Key Features

- **🖼️ Text-to-Image & Image-to-Image:** Generate artwork from text prompts or transform existing reference images.
- **🎭 56+ Customizable Art Styles:** Browse and search visual style previews, combine styles, set negative prompts, aspect ratios, quality, and reproducible seeds.
- **🌍 Community & Trending Feed:** Explore community creations with `trending` and `popular` filters, image flagging/reporting, and one-tap prompt/settings reuse.
- **🏞️ Gallery, Favorites & Fullscreen Viewer:** Manage generated images, favorite creations, toggle image privacy, download/share, and view metadata in fullscreen.
- **🎨 Dynamic Themes & Color Palettes:** Automatic or manual Dark/Light mode with a dedicated Color Palette picker.
- **🌐 13 Languages Supported:** Built-in localization for English, Arabic, German, Spanish, French, Hindi, Indonesian, Marathi, Punjabi, Portuguese, Tamil, Telugu, and Chinese.
- **🔐 Authentication & Profiles:** Firebase Auth with Google Sign-In, custom avatars, bio editing, daily quota tracking, and account deletion support.
- **🔔 Push Notifications:** Firebase Cloud Messaging (FCM) and Notifee integration.

## 🚀 Getting Started

### Prerequisites

- **Node.js** `>= 18`
- **npm** or **yarn**
- **JDK 17** & **Android Studio** (for Android builds)
- **Xcode** & **CocoaPods** (for iOS builds on macOS)
- A **Firebase** project with Google Authentication, Firestore, and Cloud Messaging enabled
- A compatible backend API for image generation and user/community endpoints

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/developer-sumit/ZenoaAI-v3.git
   cd ZenoaAI-v3
   ```

2. **Install dependencies:**

   ```bash
   npm install --force
   # or
   yarn install
   ```

3. **Install iOS pods (macOS only):**

   ```bash
   cd ios && pod install && cd ..
   ```

### Environment Configuration

Copy `.env.example` to `.env` (and `.env.production` for release builds) in the project root and fill in your credentials:

```bash
cp .env.example .env
```

```env
API_BASE_URL=your_backend_api_base_url
FIREBASE_API_KEY=your_firebase_api_key
FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
FIREBASE_MESSAGING_SENDER_ID=your_firebase_messaging_sender_id
FIREBASE_APP_ID=your_firebase_app_id
FIREBASE_MEASUREMENT_ID=your_firebase_measurement_id
GOOGLE_WEB_CLIENT_ID=your_google_web_client_id
```

> [!IMPORTANT]
> Never commit `.env`, `.env.production`, `keystore.properties`, or `.keystore`/`.jks` files to version control. They are already listed in `.gitignore`.

### Firebase & Android Keystore Setup

1. Create a Firebase project in the [Firebase Console](https://console.firebase.google.com/), enable **Google Sign-In** and **Firestore**, and download `google-services.json` into `android/app/` (and `GoogleService-Info.plist` into `ios/` for iOS).
2. Generate a release keystore for Android:

   ```bash
   keytool -genkeypair -v -storetype PKCS12 -keystore zenoa-release-key.keystore -alias zenoa-key-alias -keyalg RSA -keysize 2048 -validity 36500
   ```

3. Place your keystore in `android/app/` and create `android/keystore.properties`:

   ```properties
   storePassword=your_keystore_password
   keyPassword=your_key_password
   keyAlias=your_key_alias
   storeFile=zenoa-release-key.keystore
   ```

### Running & Building

```bash
# Start Metro bundler
npm start

# Run on Android / iOS
npm run android
npm run ios

# Lint & Test
npm run lint
npm test

# Android Release Builds
npm run build:apk   # Generates APK
npm run build:aab   # Generates AAB for Google Play
```
